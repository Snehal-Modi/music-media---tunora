# Changelog

## 1.3.0

- Renamed to Tunora
- Automated GitHub release pipeline with signed universal APK distribution (`Tunora.apk`)
- Security hardening: decoupled release signing from repository source files
- Choose your favourite artists on first launch (also in Settings)
- Queue suggestions blend several singers and never repeat a song from another release
- Playing a search result now continues with similar songs instead of the search list
- Spotify-style Home (All / Music / Podcasts chips, quick picks), Browse all search grid
- Artist and album pages, follow artists, Following tab in Library
- Fixed the lock-screen notification showing Play while music is playing
- YouTube starts faster: backup servers join after 2.5 s instead of waiting for a timeout

## 1.2.0

- Home learns your taste: *Made for you* mixes and *Because you listened to...*
- Pick your music languages; Home shows trending songs and the Top 50 chart for each
- Keep the music going: the queue refills with similar songs (can be turned off)
- Podcasts and stories: browse, search, follow, download episodes
- Offline home: downloaded songs appear automatically when there is no internet
- Fixed JioSaavn playback (new CDN links were refused) and expired-link replays
- YouTube and Audius songs fall back to JioSaavn when their stream is blocked;
  YouTube also has backup servers
- Fixed the cut-off greeting on Home
- New minion launcher icon and splash screen

## 1.1.0

- First public build: local and online playback, lyrics, downloads, equalizer
